# Mervyn 的 AI 浏览器

基于 Electron 构建的多会话 AI 浏览器。可并排打开 ChatGPT、Gemini、Copilot、Claude、DeepSeek、Qwen、Doubao、ChatGLM 等，每个会话相互独立并保留登录态。

默认界面语言为英文。

## 功能特性

- **多会话标签页** —— 每个 AI 服务可创建多个会话，各自保留页面状态，同服务共享登录态。
- **登录态持久化** —— 每个服务运行在独立的 Electron `persist:` 分区，重启或关闭标签后登录态仍保留（同一台电脑）。
- **会话与工作区恢复** —— 下次启动自动恢复标签页、当前激活项、窗口尺寸、侧边栏宽度、书签与服务列表。
- **工具栏书签** —— 常用站点（如每日签到页）一键直达；关闭网页后书签与登录态都保留。
- **AI 服务可配置** —— 左侧列表不再写死：在「管理 AI 服务」中增删改排序，或直接编辑 `services.json`（保存即生效，无需重启）。
- **页内搜索** —— `Ctrl+F` 浮动查找栏，显示匹配计数并支持上一个/下一个；仅在应用内生效，不占用系统快捷键。
- **划词发音与朗读** —— 选中单词右键查看音标、词性与发音；选中任意文本可用内置 Edge 神经 TTS 朗读。
- **自绘工具栏与菜单** —— 30px 工具栏提供 `File / View / Help`，任意网页可作为标签打开，并支持后退 / 前进 / 刷新 / 缩放 / 开发者工具。
- **主题与语言** —— 明暗主题全视图实时同步；中英文界面切换。
- **缓存管理** —— 查看各标签分区的磁盘占用，清理 HTTP/代码缓存与废弃分区，不影响登录态。
- **代理支持** —— 默认跟随系统代理（Clash / TUN 模式）；可用环境变量 `AI_BROWSER_PROXY` 覆盖。
- **开机自启动** —— 在「设置」中可开启「开机自动启动」。
- **加载容错** —— 临时性网络错误自动重试；渲染进程崩溃后自动重新加载恢复。
- **更新检查** —— 启动时静默检查并在侧边栏显示红点徽标，也可通过 `Help → Check for Updates` 手动检查。

## 打包

```bash
npm run dist       # 生成安装包 -> dist/Mervyn's AI Browser Setup x.x.x.exe
npm run pack       # 仅生成免安装目录 -> dist/win-unpacked/
```

打包产物位于 `dist/`，为 NSIS 格式安装包（可自选安装目录，自动创建桌面与开始菜单快捷方式）。

### 运行隔离实例（干净配置）

启动前设置 `MAB_USER_DATA`，即可让 MAB 使用完全独立的数据目录——会话、登录态、书签、服务列表与缓存都保存在该目录，不影响日常使用的配置。适合录制演示、测试或作为“访客配置”：

```powershell
$env:MAB_USER_DATA = "D:\mab-demo"
npm start
```

删除该目录即可让这个实例恢复为全新状态。

## 数据位置

用户数据（标签页、登录态）保存在：

```
C:\Users\<用户名>\AppData\Roaming\MyAIBrowser
```

- 同一台电脑重装/重启程序会保留标签页与登录态。
- 换到另一台电脑需要重新登录（Windows 系统对 cookie 有加密保护）。

## 设置

点击侧边栏顶部的齿轮图标打开设置：

| 选项 | 说明 |
| --- | --- |
| 开机自动启动 | 将程序加入系统登录项。 |
| 语言 | 中英文界面切换。 |
| 主题 | 明暗主题，立即同步到所有视图。 |
| 缓存 | 查看各标签分区的磁盘占用，清理 HTTP/代码缓存与废弃分区（不影响登录态）。 |
| 管理 AI 服务… | 打开服务管理窗口：添加 / 改名 / 改网址 / 移除 / 排序。 |

> **代理**不在界面中设置，请通过下方环境变量配置。

## 代理配置

默认跟随系统代理（如 Clash 的"系统代理"/TUN 模式），规则对所有标签页生效。可选地在启动前设置环境变量 `AI_BROWSER_PROXY` 以显式规则覆盖：

```bash
# Windows (PowerShell)
$env:AI_BROWSER_PROXY = "http=127.0.0.1:7890;https=127.0.0.1:7890"
npm start
```

## 管理 AI 服务

左侧 AI 服务列表支持用户自定义，配置保存在用户数据目录下的 `services.json`（Windows 为 `%APPDATA%\MyAIBrowser\services.json`），是唯一数据源：侧边栏、`文件 > 新建会话` 菜单和各服务的登录分区都由它派生。

- **应用内编辑**：打开 `设置`（齿轮图标）点击 `管理 AI 服务…`，即可添加、改名、移除或拖拽排序，更改立即生效。
- **手动编辑**：通过 `文件 > 打开 services.json` 用编辑器打开该文件，保存后自动生效、无需重启。条目结构如下：

| 字段 | 说明 |
| --- | --- |
| `key` | 稳定标识（同时决定登录分区名），新增服务时自动生成。 |
| `name` | 显示名称（同时作为默认标签页名称）。 |
| `url` | 该服务加载的首页地址。 |
| `icon` | 可选，侧边栏显示的简短文字徽标（缺省取 `name` 首字母）。 |
| `color` | 侧边栏徽标的品牌色。 |
| `logo` | 可选 logo 图片路径（`assets/logos/<名称>.png`）。 |

删除仍有打开会话的服务会先弹确认：其标签页将在下次启动时消失，登录数据保留在磁盘（可在 `设置 > 缓存` 中清理）。

各服务 logo 位于 `assets/logos/`。应用图标 `assets/icon.ico` 在重新打包后生效。

重新生成图标可运行 `python gen_icon.py`（写入 `assets/icon.ico`）。

## 安全说明

- 所有视图均关闭 `nodeIntegration` 并启用 `contextIsolation`。
- AI 站点视图运行在 `sandbox: true` 下，并使用相互隔离的 `persist:` 分区。
- 侧边栏界面设置了严格的 Content-Security-Policy，并使用 `textContent` / `CSS.escape` 防止注入。
- 没有硬编码任何凭据，登录态保存在本地用户数据目录。
- preload 脚本仅通过 `contextBridge` 暴露最小化、受限的 API。
